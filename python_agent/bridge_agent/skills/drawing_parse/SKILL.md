# 梁式桥识图（跑时）

给千问 VL 用。Cursor 改提示词时也可对照，但 **运行时只走 Python `skills/loader.py`**。

## 注入

| 节点 | 切片 |
|------|------|
| 粗看分类 | `classify.md` |
| 本轮细抽 | `units.md` + `extract_round1.md` + `piers.md` + `bearings.md` + `catalog.md` |
| 补充识别 | 同上。柱高/柱数：总布置尺寸、表格、构造图、标高差均可。支座按 `bearings.md`：本图附注定型号，本图垫石+大样定数量；禁止把伸缩缝当支座，禁止用梁距反推支座个数 |

参数全表在 `catalog.md`，不要整份塞进粗看。细抽与补充识别要带目录，才能抽出梁格/支座/桩/土所需字段。

## 产品边界

- 第一版只做梁式桥。
- **不抽钢筋明细、钢筋大样、钢束表**（对整体静力模型影响很小）。
- 看不清就空着，禁止用经验值冒充读图（尤其地质 m/Cz、二期恒载重度）。土层不全不要在识图里抄邻墩；建模才允许借用相邻墩/相近区域并标注。
- 图签页码 ≠ PDF 页序。混合图只采账本标号 + 建项幅面。
