# 支座型号、位置与数量（细抽必读）

各桥支座 **型号、墩/台是否相同、每石几块、每片几块、几排** 都以 **本图** 为准。禁止用邻桥、标准图或「每片默认两块」「台必用四氟」去填。下面的数字只是 **读图方法示例**，不是全桥通用布置。

## 先分清：支座 ≠ 伸缩缝

竣工图册里两类图常相邻，型号都写在附注里，容易抄错页。

**不要写入 `bearingType`：** `GQF`、`GQF-MZL`、`MZL`、模数式/异型钢伸缩缝、图名含「伸缩缝构造」「伸缩装置」的型号。这些进 `expansionJointType`（或只记缝宽 `expansionJointM`）。

**可以写入支座类型：** 本页附注或支座表里的 `GJZ`（普通板式）、`GJZF` / `GJZF₄` / `GJZF4`（四氟滑板，注意下标 F₄ 不要漏读成 GJZ）、盆式、球钢。盆式/球钢仍要如实抽出（建模另作硬缺口）。

## 型号与尺寸：读本页附注

1. 优先读 **垫石/支座布置图** 的附注（位置不固定：右下、图侧、图名下都有），不要用说明页或伸缩缝页上的型号顶替。
2. 先读本图 **单位**（常见：构造图厘米，平面尺寸又用 mm）。胶层厚进 `bearingRubberThickM` 时 **换成米**（附注写 7.8cm 则 value=`0.078`，unit=`m`），不要把厘米数当米。平面尺寸可读进 `bearingSize`，建模按连接单元建、**不依赖**该尺寸。
3. **仅当本图写明** 墩与台（或各墩）型号/厚度不同时，才分条：`bearingTypePier` / `bearingTypeAbutment` 等，label 带墩号或「桥墩」「桥台」。本图全桥同一型号就一条 `bearingType`，不要拆。
4. 本图若墩、台都写了，总述 `bearingType` 用原文概括（例如「墩 GJZ、台 GJZF4」）；不要只采附注后半句让全桥变成同一种。

## 位置与数量：数本图垫石 + 看本图大样

禁止默认「一石一座」或「每片一块」。步骤：

1. 在本幅（账本指定左/右/不分幅）**垫石平面**上数：横桥向几块、顺桥向几排；墩、台、各墩可能不同，分别数。
2. 用 **同页或邻页垫石/支座大样** 看 **一块垫石上画了几块支座**。大样画一块且附注未写「一石两座」→ 本图按一座一石记；大样画两块或写双支座 → 按两块记。其它画法按图。
3. 该支承处支座数 = 本幅垫石数 × 该处每石支座数（都来自本图，不要用片数反推垫石）。
4. 再与本幅 `girderCount` 对照，写出每片几块、几排；对不上就按垫石图写清楚，不要为凑片数改个数。
5. `bearingLayout` / `padStoneLayout` 用本图事实（哪一墩/台、几块、几排、每石几座）。墩台不同就分 key 或 label 带部位。

**禁止**用「梁距 × 桥宽 / 假定每片一座」反推出几百个支座。没有垫石图或支座表就留空 `bearingLayout`，不要编个数。

数量表只核对，且须分清单幅还是左右幅合计。型号写成 `GJZ250×200×28` 这类时：前两数是平面（mm），第三数是胶层厚（mm），厚要换成米进 `bearingRubberThickM`。建模里的「并联 N」是简化手法，不是图上布置，不要写进 `bearingLayout`。

## 固定 / 滑动

只在本图标明固定、滑动或四氟方向时填 `bearingFixed`。不要因为出现 GJZF 就默认全桥滑动，也不要默认台滑墩固。
