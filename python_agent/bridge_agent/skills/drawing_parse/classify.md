# 粗看分类

全书都要分类。kind 只能用下面这些词。不要抽跨径、不要读钢筋表。

| kind | 认什么 | 不要当成 |
|------|--------|----------|
| catalog | 图纸目录、卷内目录 | |
| project_notes | **竣工说明 / 工程概况 / 设计说明** 整页文字 | 图例、附注条（那是 notes） |
| notes | 图例、符号说明、附注汇编 | 竣工说明 |
| general_layout | **总体布置**：同一张上有立面+平面（常还有横断面） | 桥位平面（地形等高线为主） |
| elevation | 几乎整页都是桥梁立面，没有总体布置标题 | 墩柱钢筋立面 |
| site_plan | 桥位平面、路线平面、地形 | 总体布置 |
| cross_section | 上部构造横断面布置、跨中/支点断面（全桥宽） | 单片 T 梁一般构造 |
| quantity | 竣工数量表、工程数量表 | |
| rebar | 钢筋构造、钢筋明细、钢束 | 本产品后续不细抽 |
| pier | 墩柱/盖梁/系梁构造（非钢筋表为主的几何图） | |
| foundation | 桩位布置、承台、扩大基础、桩长详图 | |
| bearing | 支座型号表、**桥墩/桥台垫石布置**、支座大样（一页上常同时有附注） | 伸缩缝构造（GQF-MZL）、泄水孔 |
| geology | 地质柱状图、土层表、m 法参数表 | |
| archive | 封面、卷内备考表、签字页 | |
| detail | 其它大样（泄水孔、护栏、伸缩缝构造等） | |
| other | 以上都不像 | |

## 易错

- 扫描件、CamScanner 水印、页可能旋转：仍按图面内容分类。
- 「第 26 页共 80 页」是图签册内页码，JSON 的 `i` 必须是 **本书 PDF 从 1 起的页序**。
- 标题含「K130+260 (5-30m)」的数量表 → `quantity`，不是总布置。
- 总体布置附注里写「左幅数字带圈、右幅不带圈」→ 仍标 `general_layout`。
- **垫石布置图**（图名含桥墩垫石、桥台垫石、支座垫石，常带支座附注）→ 一律 `bearing`。不要因为附注显眼或旁边有大样就标 `detail` / `notes`。一石几座、每片几块以该图为准，分类时不要按「典型 T 梁布置」去猜。
- 图名含「伸缩缝」「GQF」「模数式」→ `detail`，**不要**标 `bearing`。
- 上部「空心板一般构造 / 铰缝构造」以截面几何为主 → `cross_section`；整页钢筋表才是 `rebar`。
- 图名含「墩高表」「桥墩一览」「构造尺寸表」→ `quantity`（细抽时当表格读柱高/柱数）。墩柱构造图仍是 `pier`。
- `codeHint`：图签或标题里的桩号/桥名，没有则 null。
