# 图签与单位

- 先读本页 **附注第一条单位**（常见：总体布置用 **米**；构造图用 **毫米** 或 **厘米**）。与图面数字一起换算后再填 JSON，账本跨径与结构尺寸统一用 **米**（除非目录规定别的单位）。
- 图名、图号、比例在标题栏；图名优先于零散标注。
- 幅面：账本已指定左/右/不分幅。图上「上行线/下行线」「左幅/右幅」只用来 **挑选属于本幅的跨径与墩号**，不要因为总布置画了整幅桥就失败。
- 斜桥、弯桥：跨径仍填沿跨方向的跨径组合，不要把斜长当标准跨径，除非图上明确写的是跨径。
- 标高（如 1726.60）是高程，**不是**跨径、不是墩高。柱高优先读总布置尺寸标注、墩高表、构造图柱长；没有现成长度时才用盖梁底与承台顶/桩顶标高相减。详见 `piers.md`。
- 图名「n×Lm」是跨径组合，不要把桥宽、斜长、邻孔跨径抄进 `spansM`。
