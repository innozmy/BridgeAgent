# 墩柱数量与柱高（细抽必读）

各桥墩型、每墩几根柱、每根多高都以 **本图** 为准。下面只是 **读法**，不要把某座桥的 16m 跨、三柱、φ100 当成默认。

## 柱高：多种来源，不是只能做标高差

下列任一读到就写入 `units[].supports[].columns[].heightM`（米）。**禁止**因为没看见「盖梁底高程 / 承台顶高程」就把整段 `columns` 留空。

按优先级（本页有就用，不要等专页）：

1. **总体布置立面/平面上的尺寸标注**：柱旁竖向尺寸、`H=`、`柱高`、`墩高`、`墩柱高`。构造图厘米、总布置米，先换算再填。
2. **图内表格**：墩高表、桥墩一览、构造尺寸表、数量表里按墩号列的柱高/墩高。一行一个墩号就对上 `supports.code`。
3. **墩柱构造图**上的柱长（盖梁底或墩顶至承台顶/桩顶的标注长度）。
4. **标高相减**（盖梁底 − 承台顶/桩顶）只是备选，不是唯一算法。只有标高、没有现成柱长时才相减。

不要：把地面线以上外露高度当柱长；把绝对标高（如 1726.60）当成墩高；用邻墩高度填本墩（图上写「与 n# 相同」除外，note 写来源）。

同一墩左右/中柱高度不同必须分行；相同也分行，不要合成一个数。

## 柱数：也不只靠高差

知道几根柱就写几条 `columns`（`seq` 从 1）。高度暂时读不出也要留下行，`heightM` 可空，**不要**整墩省略。

来源（本图有就用）：

- 总体布置横桥向画出几根柱（独柱 / 双柱 / 三柱）
- 图名或说明「双柱墩」「三柱式」「排架墩」
- 墩柱构造平面、盖梁下支柱数
- 表格「柱数」列

`side`：两根用 left/right；三根用 left/center/right（或图上中/边）。对不上就按从左到右 `seq`。

## 写入位置

只写 `units[].supports`。`kind` 仅 `pier` / `abutment`。沿联向 `seq` 从 0，n 跨通常 n+1 个墩台。不要把柱高再写成袋项 `pierColumnHeightM`。
