# 截面与材料

不抽钢筋。材料来自账本：主梁 `material`；墩/桩/盖梁/系梁若摘录有分项标号则分材料，否则 **允许暂用主梁标号**，note 标明 `pierMaterialFromGirder`。

## 主梁

- 按图做 **真实截面**（T、小箱、箱）：用 SAP 截面设计器或参数截面，尺寸来自横断面/构造图入账的 extracts，禁止套软件「标准 T 梁」库冒充本桥。
- 一座桥、一片梁沿跨可能有 **多种截面**（支点加厚、跨中、变截面段）。按桩号/距支点距离分段赋截面。
- **变截面简化（已定）：** 变截面前半段用变截面起点侧截面，后半段用终点侧截面，中间不建连续变化。分段点取变截面长度中点。
- 边梁、中梁顶宽不同则两个截面名。

## 墩柱、桩、盖梁、系梁、承台

- 圆/矩形/圆端/空心：用账本尺寸。变截面墩、变径桩：同主梁，简单线性变截面用中点分成两段等截面。
- 盖梁、系梁：抗弯惯性矩按图，不要用主梁截面代替。
- 无尺寸只写「有盖梁」：硬缺口，不要编 1.5×1.5。

## 砼映射（kN、m）

泊松比 0.2，重度 25 kN/m³（自重）。E 见下表，标号对不上则硬缺口。

| 标号 | E (kN/m²) |
|------|-----------|
| C30 | 3.00e7 |
| C40 | 3.25e7 |
| C45 | 3.35e7 |
| C50 | 3.45e7 |
| C55 | 3.55e7 |
| C60 | 3.60e7 |

主梁第一版若还没有截面设计器多边形，允许用账本梁高×宽度的矩形并 note `girderRectApprox`；**禁止**把案例里的 B-B/C-C/D-D/E-E 多边形抄到别的桥。

## 案例（K130+260，非通用模板）

该模型主梁是截面设计器 T 梁（B/C/D/E 分段）、盖梁变截面、墩桩 φ1500、下部 C30、主梁 C50。有账本尺寸则盖梁/系梁用矩形（可变截面以后再做）；墩/桩/盖梁材料用 `pierMaterial`，没有则暂用主梁标号。
