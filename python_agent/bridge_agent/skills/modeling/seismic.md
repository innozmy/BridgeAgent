# 抗震总则（JTG/T 2231-02—2021）

当前启用：《公路桥梁抗震性能评价细则》JTG/T 2231-02—2021。知识库未接前，不引用其它抗震规范条文号。以后启用集换规范再改本切片。

本细则 **没有**「斜交角大于 xx° 才按斜桥建」的单一限值。建模几何以总布置为准：

- 图上给出斜交角且非 0 → 按 **斜桥** 布置梁端与支座线（跨径仍用账本 `spansM`，不用斜长冒充）。
- 图上给出平面曲线半径/圆心角 → 按 **弯桥** 布主梁节点。
- 图上未标斜交、未标平曲线 → **正交直桥**，直线梁格，不要为斜/弯去补图。

细则 5.2.2：复杂曲线桥或斜弯桥等，评价时应考虑扭转，宜用多自由度反应谱或时程。那是 **分析步**；本任务 **不 RunAnalysis**。

细则适用提醒（写入模型 note，不挡开建）：跨径不超过 150m 的混凝土梁式桥、PGA≤0.4g 地区的既有桥评价；超范围只标注 `beyondJTGT2231-02`。
