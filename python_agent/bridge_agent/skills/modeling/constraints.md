# 节点约束与边界

这里的「节点约束」指 SAP **Body / Equal Constraint**（体约束或等式约束），**不是** 支座 Link，也不是桩底的「节点支座」。

## 主梁形心与支座顶

主梁是杆件，轴在截面形心；支座作用在梁底。每个支座顶节点与对应主梁划分点应 **刚体约束**（第一版用 Body 全耦合），保证一片梁多支座时整体连续、不漂。

其它「理论上应连、网格上断开」的位置（盖梁与柱顶共点失败、承台与桩顶）同样用约束，不要靠把坐标凑成完全重合却忘记连单元。

同一联连续主梁：跨界梁端节点必须共点或约束连续，禁止漏连导致一联断开。

## 刚构（墩梁固结）

图上写明墩梁固结 / 刚构：

- **不建** 该墩（该处）支座 Link。
- 柱顶（无盖梁）或盖梁顶与对应主梁节点 **Body 全耦合**。
- 多片梁时每片与盖梁/柱顶分别约束，不要漏片。

禁止刚构处再放橡胶支座「意思一下」。

## 边界「节点支座」（Restraint）

与桥梁橡胶支座不是一类东西。

- **桩底**节点：6 自由度全约束。
- **桥台处支座底**（固定点）：6 自由度全约束。
- 柱底若直接扩大基础无桩：柱底全约束。
- 有土弹簧的桩：桩底仍全约束（竖向与转动由固结承担；水平土弹簧附加在埋深段节点上，见 `soil.md`）。不要用土弹簧代替桩底竖向支承。

禁止用全约束代替上部支座 Link（刚构固结除外）。

## 案例（K130+260，非通用模板）

该模型 Body 名 `P{n}主梁-支座`、`P{n}墩-盖梁`；主梁插入点 **8 顶缘**，支座顶在梁底高程，用 Body 把形心点与支座顶耦在一起。桩底/台底约束的是 **平动三向**（转动放开）。第一版默认仍按上文 **6 自由度固结**；若以后账本标明「桩底只平动」再改，不要把这座桥的放开转动当成所有桥的规则。
