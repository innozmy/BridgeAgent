# 平面梁格几何

坐标系：X 顺桥向（或切线），Y 横桥向，Z 向上。只建本幅。单位 m。

## 联、跨、缝

- 一联 = 账本一个 `unit`；一跨 = `spansM` 中一个数；两墩之间一跨。
- **同一联内** 主梁沿跨连续，跨界不切断（连续梁）或按简支在墩顶断开主梁只靠支座传力（简支，见体系）。
- **相邻联之间** 主梁切断，两联端节点在 X 上留缝 `expansionJointM`。缝宽：图上伸缩缝/梁端间隙优先；没有则 **0.08 m**，全模型 note 标 `estimated`。
- 不要把两联编成一根通长梁。

## 梁格

- **每片主梁一根通长杆系**（边梁、中梁分截面名），片数 = `girderCount`，间距 = `girderSpacingM`。
- 横桥向用 **虚拟横梁** 连接各片，表示桥面横向刚度。虚横梁布置：优先与横隔梁位置重合；其余与 **主梁划分点** 对齐（约每 3 m 一道），不要再按 1 m 加密。
- **虚横梁截面（梁格法板条，Hambly 常用）：** 顺桥代表宽 \(b=\) 虚横梁间距（与主梁划分一致，约 3.0 m）；板厚 \(h=\) `deckSlabThickM`，否则 `concreteOverlayThickM`。再缺则要横断面，**不编板厚**。横向抗弯 \(I=b h^3/12\)；抗扭 \(J=b h^3/6\)；材料同主梁砼。虚横梁 **不计自重与质量**（避免与主梁/铺装重复）。
- 真实 **横隔梁**：账本有道数/位置/截面则另建横桥向框架，名称与虚横梁区分（`naming.md`）。

## 单元划分（防模型过大）

按构件上限等分（最后一段可略短），**不要**全桥再按 1 m 切：

| 构件 | 单段上限 |
|------|----------|
| 主梁、虚横梁、横隔梁 | **3.0 m** |
| 墩柱、盖梁、系梁、承台、桩 | **2.0 m** |

土弹簧节点与桩（及有埋深的墩身）划分点对齐，不要另外插 1 m 点。

## 弯、斜

- 正交直桥：主梁 X 轴直线。
- 弯桥：节点沿路线平面曲线，Y 随半径变化；墩平面位置按总布置（径向布置若图上如此）。
- 斜桥：梁端与支承线按斜交角，支座点沿支承线布置，不要把斜跨长当成正交跨径（跨径仍用账本 `spansM`）。

## 桥台与墩

- **不建桥台实体**。台处：地面固定点（全约束）← Link 支座 ← 主梁端（刚构台除外，罕用）。
- **桥墩必须建**：每根柱一根（或分段变截面）竖杆，柱顶接盖梁或直接接支座/主梁。
- **刚构（墩梁固结）：** 不建该墩支座 Link；柱顶或盖梁与主梁用 Body 固结（`constraints.md`）。
- 盖梁：横桥向框架，连各柱顶；有支座时支座在盖梁顶与主梁之间。
- 系梁：图上有则在对应高度横桥向连柱。
- 承台：有则用框架或刚臂连柱底与桩顶，尺寸来自图，不要编厚。
- 桩：每根桩竖杆，长度来自账本；群桩按桩位布置。

## 案例（K130+260，非通用模板）

8031test 对照模型是 **脊骨梁 + 双柱墩 + 盖梁 + 系梁**，单位 N·mm，主梁还带纵坡。本系统第一版仍是 **平面梁格（每片一根）+ kN·m + 主梁同一 Z**，不要把脊骨和纵坡抄成所有桥的默认。

该案例里 **要学** 的是：盖梁/系梁有则建；支座在梁底用 Body 连主梁形心；墩顶与盖梁 Body；桩身分段水平土弹簧；主梁插入点取顶缘；台 GJZF、墩 GJZ 按型号分；下部与主梁分标号。不要学：单梁代替片数、一支座并联代替每片、Wen 塑性（第一版 Linear）、把竖曲线抬 Z。

## 禁止

- 禁止忽略片数做成单脊骨。
- 禁止用纵曲线抬主梁 Z。纵坡本阶段不考虑。
- 禁止把标高当跨径。
- 禁止刚构墩仍塞橡胶支座。
