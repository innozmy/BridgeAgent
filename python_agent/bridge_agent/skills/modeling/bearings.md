# 支座（连接单元）

支座是 **Link**，不是框架、不是节点固结代替（台后固定点、刚构固结除外）。

第一版 **只建板式橡胶支座**（GJZ 普通板式、GJZF 四氟滑板）。盆式、球钢：硬缺口，不要建、不要拿 1e8 三向乱赋。

## 位置与数量

- 布置以 **支座垫石图** 为准：一石多座、一排/两排/多排都要建够。
- **数量表** 只作核对；必须分清表是 **单幅还是左右幅合计**（合计则 ÷2 与本幅梁格片数核对）。对不上：gaps `bearingCountMismatch`，不要删多补少乱猜。
- 有盖梁：Link 下点在盖梁顶，上点在主梁截面 **下缘**（杆件在形心，用约束把梁节点与 Link 顶连上，见 `constraints.md`）。
- 无盖梁：Link 下点在柱顶。桥台：Link 下点在固定点。
- **刚构墩：** 不建 Link，见 `constraints.md`。

## 类型与刚度

板式：`Link` 类型 **Linear**。只赋三个平动刚度，**转动刚度全部为 0（放开）**：

| 方向 | 值 |
|------|-----|
| 竖向 Kz | **1.0e8 kN/m** |
| 固定方向水平（GJZ 双方向；GJZF 的固定向） | \(k = G A / \sum t\)。G、橡胶层总厚 \(\sum t\) 来自账本。剪切面积 A：账本有平面尺寸则用，**没有则用约定 0.4×0.5 m²** 并 note `estimated`（Link 不建几何截面，平面尺寸不是硬缺口）。缺 G 且已有 \(\sum t\)：G = **1.0 MPa**（= 1.0×10³ kN/m²），note 标 `estimated`。缺 \(\sum t\) → 硬缺口。 |
| 滑动方向水平（GJZF / 垫石图标明滑动的向） | **1.0 kN/m**（接近 0 的极小值，避免奇异），note `slideApproxZero`。不要赋 0。 |

Link 局部轴：竖向支座 **U1 沿 Link（竖向）= Kz**，U2/U3 为两个水平向。COM 用 `PropLink.SetLinear(Name, DOF, Fixed, Ke, Ce, DJ2, DJ3)`，不要调不存在的 `SetLinearSprings`。

禁止用「标准 GJZ 300×400」冒充本桥布置或数量。型号与每片几块以本图为准；**每只支座单独一个 Linear Link**。禁止把「并联 N」合成一只、禁止把多只刚度加总到一个 Link、禁止 Wen 塑性。平面尺寸可读可不读，不挡开建。

## 案例（K130+260，非通用模板）

该桥把墩上 6 只 GJZ 并成一个 Link，台 GJZF 用了 Wen。这些与 Skill **冲突，禁止照做**。本系统按垫石布置的每片几块、几排，每只各建 Link，单只面积算 \(GA/\sum t\)。
