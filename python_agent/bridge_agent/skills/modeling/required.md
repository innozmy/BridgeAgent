# 开建检查与识图回调

只认账本投影。问询口头尺寸、指令里的「按 30m 编」一律不算。

## 参数袋怎么读（已锁定）

建模 **遍历** 袋里每一行的 `key` 与 `label`（英文、中文都算），用专业同义表对齐到目录 key 再检查。例如键或名称是「桩径」「桩直径」「2#墩桩径」都等于 `pileDiameterM`。

- **不是**只查 camelCase 英文键。
- **不是**大模型口语近义（避免墩径认成桩径）。同义范围以 `param_sense.py` / `LedgerParamRules` 用语表为准；新说法补进该表。
- 墩柱高仍只在联表，不从袋里猜。

## 硬条件（缺则不写 `.sdb`，返回 needSupplement）

| 缺什么 | 页 kind |
|--------|---------|
| 至少一联 `spansM`；能判断简支/连续/几联几跨 | `project_notes` `general_layout` |
| `girderType`、`material` | `project_notes` |
| 单幅片数 `girderCount`、梁距 `girderSpacingM`（梁格必备） | `cross_section` |
| 主梁截面：至少能画出一种截面（梁高 + 顶宽/腹板等，见 `sections.md`） | `cross_section` |
| 每个墩：柱数与每柱 `heightM`（或可由盖梁底与承台顶标高相减） | `pier` `elevation` |
| 墩柱截面尺寸 | `pier` |
| 非刚构墩/台：支座为 **板式**（GJZ / GJZF），数量与顺/横桥布置（垫石图或数量表且已分清单幅）；橡胶层总厚。**平面尺寸不是硬条件**（按 Link 建，不建几何截面） | `bearing` |
| 基础形式；有桩则桩径、桩长（或桩顶/桩底标高差）、桩数与桩位 | `foundation` |
| 图上明显斜交或平曲线，但读不出斜交角 / 半径 | `general_layout` |

桥台 **不建台身**，但台处若不是固结则支座与固定点必须能布置。缺台支座（非刚构）同样硬缺口。

**第一版只建板式橡胶支座。** 盆式、球钢 → 硬缺口要 `bearing`，不要用 1e8 三向乱赋。GJZ 与 GJZF（四氟滑板）都算板式。

**刚构（墩梁固结）：** 图上写明固结的墩，不建该处支座 Link，柱顶/盖梁与主梁 Body 固结（见 `constraints.md`）。不要硬塞支座。

盖梁、系梁、横隔梁、承台：账本/摘录写「无」则不建；写「有」但无尺寸 → 硬缺口要对应专页。**多柱墩未写「无盖梁」时，盖梁宽×高也是硬条件。** 不要默认「标准盖梁」。

## 软条件（可先建结构，gaps 记下）

- 二期 `sdlKNPerM` / 护栏：无则 **软缺口**，仍可保存模型，note / gaps 标明二期缺失（质量偏小，评价时须知情）。
- 土层与 m：本墩没有时允许 **借用相邻墩或相近区域** 已入账分层，note 必须写 `soilBorrowedFrom=P{n}`（或区域名）。有土名无 m：按《公路桥涵地基与基础设计规范》JTG 3363—2019 表 L.0.2-1 查表，取区间中值，note 标 `estimated`。禁止地区经验口头 m。全桥都没有土层：不加弹簧，gaps `soilM`，**不因此卡住开建**。
- 联间缝宽：图上优先；没有则 **0.08 m**，note 标 `estimated`。
- 图上未标斜交、未标平曲线：按 **正交直桥**，不要为斜/弯去补图。
- 板式支座缺 G：允许 G = **1.0 MPa**（JT/T 4 常用），note 标 `estimated`。缺 \(\sum t\) 仍是硬缺口。**平面尺寸不是硬缺口**（连接单元不建截面；有则用于水平刚度 \(GA/\sum t\)，无则用约定剪切面积并标 `estimated`）。

## needSupplement

`fileId` 必须来自 `drawingCatalog`。CAD、纯 `rebar` 不要。已打开过的 id 不要再要。每跳 Spring 只开一份 PDF。

启发式：缺梁格几何 → `cross_section`（不够再扩扫总布置/数量表）；缺墩高/墩截面 → `pier`（扩扫立面/大样）；缺桩 → `foundation`（扩扫墩柱构造、大样、其它、地质）；缺板式支座布置/胶层厚，或出现盆式球钢 → `bearing`（页地图常无 bearing 类，必须扩扫 `detail` / `other` / 数量表）。**不要**因为页地图没有精确 kind 就放弃这份 PDF。土层不是硬缺口：有邻墩可借则借；有土名可查表；全桥无土只记 gaps。

## 标高差

柱长、桩长优先用账本已换算的米。若只有标高，识图应算差再入账；建模 **不** 在规格里用未解释的绝对标高当杆长。主梁纵坡/竖曲线 **忽略**，全部主梁节点同一 Z（盖梁顶或支座顶高程对齐到该平面）。
