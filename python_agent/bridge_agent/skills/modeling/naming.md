# 命名

所有点、框架、Link 必须能读出 **第几联、第几跨、P 几墩 / 台、第几片梁**。禁止 `Frame1` `Link2`。

建议语法（ASCII，SAP 名称长度限制内截断时保留尾部编号）：

| 对象 | 模式 | 例 |
|------|------|-----|
| 点 主梁 | `J-U{联}-K{跨}-G{片}-{顺桥序号}` | `J-U1-K3-G2-015` |
| 点 墩柱 | `J-P{墩号}-C{柱}-Z{高程序号}` | `J-P2-C1-Z00` |
| 点 桩 | `J-P{墩}-PL{桩}-{序号}` | `J-P2-PL3-008` |
| 点 台固定 | `J-ABUT{0或N}-G{片}` | `J-ABUT0-G2` |
| 主梁杆 | `F-GIR-U{联}-K{跨}-G{片}-{段}` | `F-GIR-U1-K2-G1-004` |
| 虚横梁 | `F-VTB-U{联}-K{跨}-{顺桥序号}` | `F-VTB-U1-K2-010` |
| 横隔梁 | `F-DIA-U{联}-K{跨}-{道}` | `F-DIA-U1-K2-D1` |
| 盖梁/系梁 | `F-CAP-P{墩}` / `F-TIE-P{墩}-L{层}` | |
| 墩柱/桩 | `F-COL-P{墩}-C{柱}-{段}` / `F-PIL-…` | |
| 支座 Link | `L-BRG-P{墩或ABUT}-G{片}-R{排}-N{只}` | `L-BRG-P2-G1-R1-N2` |
| 约束 梁-支座 | `C-GIRBRG-…` | 与被连点同名族 |
| 约束 刚构 | `C-RIGID-P{墩}-G{片}` | 柱顶/盖梁与主梁 |

墩号与账本 `supports.code` 一致（`1#` 写成 `P1` 或 `1`，全模型统一一种）。跨号从 1 按联内从左到右。片号从 1 横桥向排列（与总布置左/右幅朝向一致，note 写清）。

COM：`AddCartesian` / `AddByPoint` 的 **UserName** 才是对象名；把名字传进 OUT 的 `Name` 参数，SAP 仍会命名成 `1` `2` `3`。

## 案例（K130+260，非通用模板）

该模型用 `L0` `DTZ1` `GLZ1` `ZZZ0` 等短名。第一版仍用上表 ASCII 族名，便于对账本联/墩/片；不要为了像案例而改成无联号的短名。
